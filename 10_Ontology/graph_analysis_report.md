## 🔗 5. 강한 연결 경로 (Strong Paths)

### Path 1: 저자 → 방법론 → 적용
```
심재우 → created → GE 비즈니스 방법론
         → includes → 세일즈 프로세스 13가지 성공법칙
                     → includes → Boss Managing
```
**의미**: 저자가 만든 방법론이 실무 기법으로 구체화

### Path 2: 리더 → 조직 → 산출물
```
잭웰치 → leads → GE
        → produces → GE 비즈니스 방법론
                    → includes → 변화리더십 101
```
**의미**: 리더십이 조직을 통해 방법론으로 체계화

### Path 3: 역량 모델 → 교육 프로그램
```
4E + V → part_of → Energy, Energize, Edge, Execute, Values
       ↓ (inferred)
GE → uses → Executive Program
           → (based_on) → 4E + V
```
**의미**: 역량 모델이 교육 프로그램의 기반

### Path 4: 리더십 프레임워크 → 개별 역량
```
9가지 핵심 리더십 → includes → Energy
                            → Energize
                            → Vision Maker
                            → Edge
                            → Execute
                            → Integrity
                            → Communication
                            → Risk-Taking
                            → Sharing & Celebration
                            → Excellence & Competency
```
**의미**: 종합적 리더십이 10가지 구체적 자질로 분해

## 💡 6. 주요 인사이트

### 1. 계층적 구조 (Hierarchical Structure)
그래프는 명확한 3단계 계층을 보임:
- **Level 1**: 통합 방법론 (GE 비즈니스 방법론)
- **Level 2**: 영역별 방법론 (세일즈, 리더십, 인재육성)
- **Level 3**: 구체적 기법 및 역량 (Boss Managing, Energy 등)

### 2. 중복 개념 발견
다음 노드들이 2개 이상의 클러스터에 속함:
- **Energy**: 4E+V와 9가지 리더십 모두에 포함
- **Energize**: 4E+V와 9가지 리더십 모두에 포함
- **Edge**: 4E+V와 9가지 리더십 모두에 포함
- **Execute**: 4E+V와 9가지 리더십 모두에 포함

**제안**: 이들은 하나의 개념으로 통합하거나, 맥락에 따라 구분 필요

### 3. 저자의 영향력
**심재우 저자**는:
- 6개 산출물 생성 (가장 높은 Out-Degree in Person 카테고리)
- GE에서 실무 경험 → 방법론 창작 → 저술 활동
- 지식 그래프의 핵심 기여자

### 4. GE의 중심성
**GE**는:
- 조직으로서의 중심 (Company 노드)
- 방법론 생산자 (produces)
- 교육 프로그램 운영자 (uses)
- 인물들의 활동 무대 (leads, worked_at)

→ 전체 지식 체계의 **물리적 기반**

### 5. 약한 연결 영역
다음 노드들은 연결이 약함:
- **Estee Lauder**: 1개 연결만 (사례 기업으로 언급)
- **BBC**: 1개 연결만 (심재우의 소속)
- **1% 위대한 기업**: 1개 연결만
- **타운미팅**: 1개 연결만

**제안**: 원문 재분석을 통해 추가 관계 발굴 필요
