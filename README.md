# 📚 Knowledge Vault Browser

Obsidian 없이 웹 브라우저에서 바로 사용할 수 있는 지식 관리 시스템

---

## 🚀 빠른 시작

### 방법 1: 더블클릭 (가장 쉬움!)
```
knowledge_vault_browser.html 더블클릭
→ 크롬/엣지에서 자동 실행
```

### 방법 2: 명령줄
```bash
start knowledge_vault_browser.html
```

## ✨ Obsidian 기능 구현

### ✅ 구현된 기능

| 기능 | 설명 | 단축키 |
|------|------|--------|
| **📁 파일 트리** | 폴더별 파일 구조 탐색 | - |
| **🔍 전체 검색** | 파일명 실시간 검색 | Ctrl+F |
| **📄 Markdown 렌더링** | 실시간 마크다운 변환 | - |
| **🔗 내부 링크** | [[링크]] 클릭 가능 | - |
| **🌐 그래프 뷰** | 지식 그래프 시각화 | - |
| **📊 CSV/JSON 뷰어** | 데이터 파일 표 형태로 표시 | - |
| **🏷️ 태그 표시** | Frontmatter 태그 추출 | - |
| **📑 파일 정보** | 메타데이터 표시 | - |
| **🎨 다크 테마** | Obsidian 스타일 UI | - |
| **↔️ 3단 레이아웃** | 좌측 파일 트리, 중앙 콘텐츠, 우측 정보 | - |

### 🎯 주요 기능

#### 1. **읽기 뷰 (Reading View)**
- Markdown 파일 렌더링
- Frontmatter 자동 파싱
- 내부 링크 [[링크]] 클릭으로 이동
- 코드 블록 하이라이팅
- 표, 인용구, 리스트 완벽 지원

#### 2. **그래프 뷰 (Graph View)**
- D3.js Force-Directed Layout
- 노드 드래그 앤 드롭
- 줌/패닝
- 라벨 토글
- 중앙 정렬

#### 3. **파일 트리**
- 폴더별 구조화
- 파일 아이콘
- 클릭으로 파일 열기
- 실시간 검색 필터링

#### 4. **우측 사이드바**
- 파일 정보 (크기, 라인 수)
- 태그 추출 및 표시
- 백링크 (계획)
- 아웃라인 (계획)

## 📖 사용 가이드

### 파일 열기
1. 좌측 폴더 클릭 → 파일 목록 표시
2. 파일 클릭 → 중앙에 내용 표시

### 검색
1. Ctrl+F 또는 검색창 클릭
2. 파일명 입력 → 실시간 필터링

### 그래프 보기
1. 상단 [🌐 그래프] 버튼 클릭
2. 노드 드래그로 이동
3. 마우스 휠로 줌
4. 우측 컨트롤:
   - 🔍 리셋: 줌 초기화
   - ⊙ 중앙: 그래프 중앙 정렬
   - 🏷️ 라벨: 라벨 숨기기/보이기

### 내부 링크
- Markdown 내 [[링크명]] 클릭
- 자동으로 해당 파일 열림

### CSV/JSON 보기
- CSV 파일: 표 형태로 렌더링 (최대 50행)
- JSON 파일: 포맷팅된 코드로 표시

## 🎯 사용 시나리오

### 1. **프레젠테이션**
```
회의실에서 knowledge_vault_browser.html 열기
→ 지식 그래프 시연
→ 노트 클릭하며 설명
```

### 2. **공유**
```
Vault 폴더 전체를 압축
→ 동료에게 전송
→ 압축 해제 후 HTML 실행
→ Obsidian 설치 없이 바로 탐색
```

### 3. **백업 뷰어**
```
Vault 백업본 생성 시 HTML 포함
→ 나중에 백업본만으로 내용 확인 가능
```

### 4. **웹 호스팅**
```
GitHub Pages에 업로드
→ 브라우저에서 어디서나 접근
→ 팀원들과 공유
```

## 🐛 문제 해결

### 파일이 안 열려요
→ 파일 경로가 상대 경로로 설정되어 있습니다.
→ `knowledge_vault_browser.html`을 Vault 루트에 두세요.

### 그래프가 안 보여요
→ `10_Ontology/ontology_graph.json` 파일이 있는지 확인
→ 브라우저 콘솔 (F12) 에러 확인

### 내부 링크가 안 돼요
→ 링크 대상 파일이 실제로 존재하는지 확인
→ 파일명이 정확한지 확인 (대소문자 구분)

### 한글이 깨져요
→ HTML 파일을 UTF-8로 저장
→ 브라우저에서 인코딩 UTF-8 확인
